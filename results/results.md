## Method

- CPU ms and logical reads: delta of `sys.dm_exec_sessions.cpu_time` / `logical_reads` for the benchmark's own session around each run.
- Elapsed ms: client-side `Stopwatch` around execution including reading all rows.
- `cpu_time` is reported by Windows in ~15.6 ms ticks, so very fast queries show 0 or 15-16 ms CPU; logical reads are exact.
- Warm cache: logical reads are independent of caching; elapsed times on a cold cache (physical I/O) would be higher for the 'before' queries.
- Raw per-run numbers: [`results.csv`](results.csv); medians: [`summary.csv`](summary.csv).
